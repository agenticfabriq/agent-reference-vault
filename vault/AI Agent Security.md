# AI Agent Security

**AI agent security** covers controlling what autonomous AI agents can access and do: [[Agent Identity]], authorization, credential handling, human oversight and audit. Vendors in this category include identity incumbents adding agent features and agent-native companies such as [[Agentic Fabriq]].
