# Refusal Rate

**Refusal rate** (or deferral rate) is the share of questions a [[Text-to-SQL]] or agent system declines to answer. It's the check on any accuracy figure: a system that never declines can look more accurate than one that declines what it would get wrong. Refusal is *calibrated* when declined items are ones the system would more often miss.
