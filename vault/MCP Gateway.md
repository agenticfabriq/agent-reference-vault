# MCP Gateway

An **MCP gateway** is a service between AI agents and tools exposed via the [[Model Context Protocol]] that authenticates the agent, enforces policy on each tool call, attaches credentials so the agent never holds them, and logs the call. Example: [[Fabriq Developer]].
