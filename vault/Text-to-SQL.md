# Text-to-SQL

**Text-to-SQL** is generating SQL from a natural-language question so a system can answer it from a database. Measured on benchmarks like [[BIRD]] and [[Spider 2.0]], though scores depend heavily on the grading rule and do not reliably transfer to a new database.
