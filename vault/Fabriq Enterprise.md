# Fabriq Enterprise

**Fabriq Enterprise** is [[Agentic Fabriq]]'s control layer for AI agents running inside an organization. It gives each agent an [[Agent Identity]], scopes actions to the user the agent acts for ([[On-Behalf-Of Delegation]]), enforces [[Fail-Closed Authorization]], routes high-risk actions to human approval, and records an audit trail across SaaS tools, [[Model Context Protocol|MCP]] servers and databases.

It connects to existing identity providers rather than replacing them.
