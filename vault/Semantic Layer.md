# Semantic Layer

A **semantic layer** maps business concepts to database structures: definitions, join paths, metrics and value mappings. In [[Text-to-SQL]], context ranges from raw DDL to *certified meaning* reviewed by someone accountable for the data; the level used should be reported with any accuracy figure.
